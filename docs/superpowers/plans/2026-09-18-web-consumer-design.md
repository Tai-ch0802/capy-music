# `capy --web` 視覺規格 v2:面向一般使用者(2026-09-18)

> 本文件是 [2026-09-18-web-consumer.md](2026-09-18-web-consumer.md) 決策 45–48 的完整規格,T1 / T2 照這份實作。它是對既有介面的**重新設計**(不是從零開始),與 [v1(2026-09-17)](2026-09-17-web-mode-design.md) 衝突的地方以本文件為準;§2 逐條列出哪些留、哪些退役。
> 使用者原話:「現在介面有點太工程師了 … 更面向大眾使用者 … 更生動的動畫、示意圖 … 我們主打開源、免費。」v1 的「geek 綠、冷冽霓虹、cyberpunk」也是使用者的話,所以綠與水豚留下來當品牌,退役的是「看起來像終端機」的那些東西。

## 1. 設計讀法與 dial

**讀法**:給「想換串流平台、不想為了搬歌單付錢」的一般聽眾用的本機小工具;語氣是友善、篤定、說實話;視覺是深色音樂 app 的語言(大字、圓角、留白、一個綠),終端機退到「進階」。

- variance 6:首頁左文右圖的不對稱開場;其餘頁面規矩。
- motion 6:示意動畫循環 + 進場錯落 + 按壓回饋;只動 `transform` / `opacity`。
- density 3:首頁一屏只講一件事;資料頁(清單、同步表)維持可讀的密度,不硬撐留白。

## 2. v1 的規則:留下的與退役的

## 4. 字

- `--sans`:`-apple-system, "SF Pro Text", "PingFang TC", "Noto Sans TC", "Microsoft JhengHei", "Segoe UI", system-ui, sans-serif`。介面是中文優先,系統字在三個 OS 上都是該平台最好讀的中文字;不內嵌字型(Q37 的結論不變:零二進位 vendor)。
- `--mono` 只用在:主控台、ID、時長 / 計數(`font-variant-numeric: tabular-nums`)。
- 字級:`--t-12 / 14 / 16 / 20 / 28 / 40`。首頁標題 40(手機 28)、`font-weight: 700`、`letter-spacing: -0.02em`、`line-height: 1.15`、`text-wrap: balance`;頁標題 28;區塊標題 20;內文 16 / 1.7、最寬 34em;輔助 14;標籤 12。權重用 400 / 500 / 600 / 700 四級。
- 句子式標題,不用全大寫標籤、不用驚嘆號。

## 5. 形狀與層次

- 一條圓角規則,全站照用:**容器(卡片、dock、對話框)`--r-lg: 16px`;控制項(按鈕、輸入框、chip、表格外框)`--r: 10px`;主要動作鈕是膠囊(`999px`)**。沒有第四種。
- 卡片只在「這是一個可以操作的物件」時出現(平台卡、清單列、步驟面板);說明文字不包卡片,用留白與細線分組。
- 陰影帶綠的深色(`0 8px 24px rgb(4 12 8 / .45)`),只給浮起來的東西(選中的平台卡、步驟面板)。
- 首頁背景:`--ink` 上一層很淡的放射狀綠光(`radial-gradient`,accent 6% 透明度,左上),不是線性漸層、不是紫藍。

## 6. 版面

- **外殼**:左 rail(`15rem`;≤ 720px 變成頂部橫列)、main(內容欄 `max-width: 72rem`、padding 2rem)、dock(播放列 + 執行狀態列;命令列只在主控台頁)。
- **「進階」的收合**:路由落在主控台 / ISRC / 診斷任一頁時(單鍵 6–8、網址列、重新整理都算)`<details>` 一律打開——active 樣式與鍵盤焦點不能落在看不見的地方。≤ 720px 時 rail 是會換行的橫列,「進階」展開後三個項目接在同一個橫列裡往下換行,不浮層、不蓋內容。
- **rail**:品牌(水豚小頭像 + `capy`)、五個主要項目(搬家 / 我的清單 / 同步 / 搜尋 / 帳號,各帶一個單色字符:⇄ ♪ ⟳ ⌕ ☺ 一類的 Unicode,不手畫圖示)、`<details>` 的「進階」(主控台 / ISRC 查詢 / 診斷)、底部版本。active = accent 淡底 + 左側 3px accent 條。鍵位提示 1–8 留著(小、muted)。
- **搬家頁(首頁)**,由上到下:
  1. **開場**(不是 100vh;桌面左文右圖,手機上下疊):左邊標題「把歌單搬過去,一首都不用重找。」、一句副標(免費、開源、在你自己的電腦上跑)、三個事實 chip(`免費` `開源 MIT` `不經過任何人的伺服器`);右邊是**路線示意**:來源卡 → 水豚 → 目的地卡,音符小卡沿路線流過去(§7)。來源與目的地卡就是步驟 ① 的選擇結果,所以示意圖是活的:換了平台,圖跟著換。
  2. **步驟面板**(一張大卡,頂端三段進度「① 選路線 ② 選清單 ③ 確認並搬家」;目前步驟 accent、完成的打 ✓、未到的 muted;不是裝飾編號——這真的是一個有順序的流程)。
  3. **它怎麼搬的**:三拍說明,左右交錯(不是三張等寬卡片):讀(讀出清單的每一首)→ 對(用每首歌的國際編號 ISRC 找到同一首,找不到才用歌名與歌手比對,沒把握的會問你)→ 建(在目的地建一個同名清單,照原本的順序放進去)。每拍配一個小的循環示意(§7)。
  4. **先說清楚的事**:兩欄細線分組的短句——不刪來源、只新增;順序不動;Apple Music 目前只能當來源;連接帳號要花幾分鐘(你用的是你自己的憑證,所以沒有人能替你付費牆);清單正本在你的 Google Drive。
  5. 頁尾一行:開源、原始碼連結、使用指南。
- 其餘各頁:頁標題 28 + 一句白話說明;動作鈕白話;表格外框圓角、列高 40、表頭 12 muted;空白態 = 一句話 + 一顆主要動作鈕。

## 7. 動效

- token:`--dur-1: 120ms`(按壓)、`--dur-2: 200ms`(hover / 選中 / 進場)、`--dur-3: 1.2s`(脈衝)、`--dur-loop: 6s`(示意動畫一輪)、`--ease: cubic-bezier(.2, .7, .2, 1)`。
- **按壓**:`transform: scale(.98)`;hover:底色與邊框 `--dur-2`。
- **進場**:搬家頁的開場、步驟面板、三拍說明各自 `opacity 0→1 + translateY(12px→0)`,依序延遲 80ms;**靜止狀態就是可見的**(用 `animation … both` 從可見的最終幀回推,JS 沒跑、動畫被關都看得到內容)。
- **路線示意(裝飾,決策 47)**:三張音符小卡(兩條灰線 + 一個 ♪)以 `translateX` 從來源卡滑到目的地卡,錯開 2 秒,經過水豚時 `scale(.9)` 一下;水豚每 4 秒眨眼(`opacity` 切兩個眼睛圖層)。來源 / 目的地卡在選定時 `--dur-2` 的邊框與淡底變化。
- **三拍說明的小示意**:讀 = 三列依序淡入;對 = 兩張卡靠攏後中間出現 ✓;建 = 三列由下往上依序落定。全部 `--dur-loop` 循環、只動 `transform` / `opacity`。
- **真實進度**(T3):進度條是 `transform: scaleX()`,值只來自 `progress` 事件;沒有事件時不畫進度條,只有階段文字與計時。命令在跑的時候,路線示意停在靜態構圖,不拿裝飾動畫冒充進度。
- `prefers-reduced-motion: reduce`:所有循環與進場 `animation: none`,示意圖停在「一張小卡在路線中間」的靜態構圖;按壓與 hover 的過渡歸零。

## 8. 元件

- **主要按鈕**:膠囊、accent 底、ink 字、600、高 48(首頁)/ 40(其餘);hover 亮 6%(`filter` 不用,換 `--accent-hi: #5CC596` 底色);disabled `opacity .45`。一頁最多一顆。
- **次要按鈕**:`--r`、surface-2 底、line-hi 框、text 字。**文字鈕**:accent 字、無框,用在「改用既有清單」這類次要選擇。**中止**:次要按鈕 + danger 字與框。
- **平台卡**(步驟 ①):`--r-lg`、surface-2、上方單色字符(♪ / ● / ▤ 一類)與平台名(20 / 600)、下方連線狀態(`✓ 已連接` accent / `需要連接` warn + 「連接」文字鈕 / `目前只能當來源` muted)。選中 = accent 邊框 + accent 淡底 + 陰影。不可選 = `aria-disabled` + muted + 一句原因,不是直接消失。
- **清單列**(步驟 ②):單選;名稱 16 / 500、曲數 mono muted、選中 = accent 淡底 + ✓。超過 8 筆出現過濾輸入框。
- **提示(就地)**:步驟面板裡的一張 accent 邊框卡;標題用 CLI 的原句(不改寫——那是伺服器問的話),按鈕用 CLI 的原字(「套用」/「取消」);Apple 揭露的 note 是 warn 左線、不可收合。
- **完成報告**:大數字(搬了幾首,tabular)+ 一句話;「沒搬到的歌」清單(歌名 — 歌手 · 原因);兩顆鈕:「再搬一個」「讓兩邊保持同步 →」。
- **事實 chip**:`--r`、line 框、14、無底色;不是可點的東西就不要長得像按鈕。

## 9. 文案

- 對使用者說「你」,主動語態,動詞開頭的按鈕(「開始搬家」「連接 Spotify」「再搬一個」)。
- 不用:一鍵、無縫、輕鬆、強大、支援所有平台;不用驚嘆號;錯誤說發生了什麼 + 怎麼辦。
- 術語第一次出現給一句白話:ISRC =「每首歌的國際編號」;正本 =「capy 替你存在 Google Drive 的那一份清單」。
- 伺服器送來的原文(提示標題、stderr)逐字呈現,不翻譯、不改寫;原文裡若帶著 CLI 命令(migrate 的「現在逐筆裁決?」那一則),照留,精靈在旁邊補一句白話。pre-flight 1 管的是頁面自己的文案。

## 10. pre-flight(T1 / T2 的 PR 逐條勾)

1. 第一眼沒有命令字串(主控台除外)。2. 一頁一顆主要按鈕。3. 圓角只有 16 / 10 / 膠囊三種。4. 綠只有一個;沒有紫藍漸層、沒有純黑純白。5. 灰階同一個色相。6. 內文 ≤ 34em、標題 `text-wrap: balance`。7. 動畫只動 `transform` / `opacity`,有 reduced-motion 的靜態版。8. 靜止狀態就看得到全部內容。9. 裝飾動畫不冒充進度。10. 不可用的選項是灰的並說原因。11. 400px 無橫向捲動、觸控目標 ≥ 40px。12. 鍵盤走得完整個精靈,焦點環看得到。13. 沒有官方 logo。14. 首頁每一句主張都查得到出處(決策 48)。15. CSP 零 inline 照舊(動畫全在 CSS 檔)。
