## §1 本次拍板的決策(2026-09-17;附錄 C 決策 40–44)

### 決策 40:`capy --web` 的形狀 —— 行程內執行、一次一個命令、接縫換成瀏覽器回答、表格走 `ui.TableWriter`

**問題。** 使用者要「所有 CLI 指令都能透過 web 執行、畫面更豐富」。TUI 為了「行程內 stdout 不是 TTY 會退成 TSV、huh 提示會搶 stdin」選了 re-exec(`tui.go:33`);但結構化表格與瀏覽器回答提示只有行程內拿得到。行程內的代價是所有互動 / TTY / stderr 接縫都是 process 級 var,`defaultProvider` 是無同步的 `sync.OnceValue`,並行 job 就是 data race。三條路線(行程內 / 子行程 / 混合)各一份提案、三位評審逐條對地圖驗證:行程內 41 分勝出;子行程的互動層落在 Go 測不到的 app.js(子行程連不到 fakeSpotify,`provider.go:169-175` 刻意不吃 env)、cookie 依 RFC 6265 不分 port 會把 token 送給 127.0.0.1 其他 port、Windows 只能 TerminateProcess;混合案的唯讀並行類別在 `resetDefaultProvider()` 上被三位評審一致判 data race。

**定案。**

1. **執行模型**:`POST /api/run` body `{"args":[…]}` 或 `{"line":"pl show \"上班 通勤\""}`(line 非空就伺服器端 `splitArgs`;兩者都空 = `[]string{}`,**絕不 nil**)。流程:純字串 deny(第 5 點)→ `s.runMu.TryLock()` 失敗回 409 → 鎖內 `resetDefaultProvider()`(長駐行程要看到終端機改的 config.json)→ `root := newRootCmd()` → `root.Find(args)` 用**這個 job 自己的樹**查 `CommandPath()` 是否在允許清單(cobra `Flags()` 是 lazy init,共用靜態樹在 -race 下會被抓)→ `root.SetOut(&webStdout{sse})` / `SetErr(&webStderr{sse})` / `SetArgs(args)` → `root.ExecuteContext(jobCtx)` → `code, msg := ExitCode(err)` → exit 事件。同步在 handler goroutine 裡跑,不開背景 goroutine、不做 job registry。**不變式(寫進 `web.go` 檔頭)**:Serve 開始後,`newRootCmd()`、`defaultProvider()`、`resetDefaultProvider()`、任何 var 接縫、三個匯出 stderr 全域的**寫入**,只在 `runMu` 內發生;允許清單與 `/api/commands` 的命令樹在 Serve 前算一次;`/api/now`、`/api/isrc` 兩個直達端點不經 cobra、不碰接縫、不呼叫 `defaultProvider()`。`s.cur *webJob` 由 `curMu` 守,是唯一的「目前 job」;橋接接縫從它取 job,`s.cur == nil` 時回明確錯誤而不是掛住。exit code 直接沿用 `ExitCode`;130 在 web 走不到(pager 開不了)。
2. **取消三路匯到同一個 ctx**:`jobCtx, cancel := context.WithCancelCause(r.Context())`;`context.AfterFunc(s.ctx, …)` 把伺服器 SIGINT / SIGTERM(`Execute()` 既有的 `signal.NotifyContext` → `cmd.Context()`)接進來;`POST /api/jobs/{id}/cancel` 第三路。**handler 解完 JSON 後 `io.Copy(io.Discard, http.MaxBytesReader(w, r.Body, 1<<20))` 讀到 EOF**:net/http 對有 Content-Length 的 body 要讀到 EOF 才起 background read、連線斷掉才會 cancel `r.Context()`,沒有這行「關分頁即放鎖」不成立(`TestWebDisconnectCancelsJobAndPrompt` 是它的 fails-before-fix 回歸測試)。取消生效點與 CLI 相同(下一個 HTTP 請求、`Backoff.Wait`、`LockFile` 輪詢;osascript / keychain / 純 CPU 段不吃 ctx)。exit 事件帶 `reason: done | cancelled | timeout | shutdown`(`context.Cause`),`ExitCode` 不動:使用者取消浮上來的 `context.Canceled` 是 exit 1「Error: context canceled」,與終端機 Ctrl-C 一致,前端依 reason 顯示「已取消」而不是錯誤。伺服器關閉:AfterFunc 砍 job → pending 提示回取消值 → 零寫入退出 → `srv.Shutdown(5s)`。
3. **提示橋**:伺服器→瀏覽器走同一條 `/api/run` 的 SSE 串流 `{"type":"prompt","id":N,"kind":"confirm|select|input|form","title","note":{"title","body"},"options":[…],"fields":[{"name","label","secret"}],"affirmative","negative","default","error"}`;瀏覽器→伺服器 `POST /api/jobs/{job}/answer` `{"id":N,"cancel":false,"value":<bool|int|string|{name:value}>}` → 204;`cancel:true` = Esc / 關掉。`ask` 以 pendingID 簿記:`job.mu` 下設 `pendingID` 再送事件,`select` 等 `answers`(cap 1)/ `jobCtx.Done()` / 逾時;`handleAnswer` 比對 `a.ID == pendingID`(不符或沒有 pending → 409)並清掉再送進 channel,重複 POST 與遲到的舊答案進不了下一個 prompt;逾時 / ctx 取消也清 pendingID 並送 `{"type":"prompt_closed","id":N,"reason":"answered|dismissed|timeout|cancelled"}`。伺服器驗型別與範圍(不合 400);接縫層驗證失敗(`validateSpotifyClientID`、`validateAppleDevToken`、必填)→ 同 kind、新 id、帶 `error` 重問。`secret:true` 的值只在 answer body 裡經 loopback 進行程,不進任何事件、不記 log、不回顯。**提示逾時 `webPromptTimeout = 5 * time.Minute` 是 job 級**:逾時先 `cancel(errPromptTimeout)` 再回該接縫的取消值,讓 `reviewLoop`(`resolve.go:438-455`,逐筆問)的下一筆立刻回 `ErrUserAborted` → 整輪不寫入 exit 2、pull.lock 立刻放;逾時只套用在會握 pull.lock 的路徑,`auth login *`(不取任何鎖;Apple 使用者要開 DevTools 抄兩個 token)不設逾時,斷線仍取消、180 s 授權逾時仍由 cli 層給。前端在 job 執行中註冊 `beforeunload`。

### 決策 41:安全模型 —— 只綁 127.0.0.1、一次性 token、Host / Origin 檢查、憑證絕不進頁面

**問題。** loopback HTTP 伺服器的攻擊面是其他瀏覽器來源:DNS rebinding、跨站 fetch、127.0.0.1 其他 port 的頁面(repo 內現成的就是 8888 回呼伺服器);cookie 依 RFC 6265 不分 port,SameSite 對 127.0.0.1 其他 port 完全不擋;`debug apple-token` 印 keychain 明文;精靈輸入的 secret 要經 HTTP 進行程。

**定案。** **綁定**:只 `net.Listen("tcp", "127.0.0.1:<port>")`,永不 `0.0.0.0` / `::`;`--port` 預設 0(動態,同 Google loopback),`--port 8888` 在 listen 前拒絕「8888 是 Spotify 授權回呼固定 port」,被占用直接失敗不退讓;`auth login spotify` 在 web 行程內綁 8888 loopback 沒衝突。**Token**:`auth.NewState()` 一次產生;URL 印成 `http://127.0.0.1:<port>/#t=<token>`——fragment 不送到伺服器、不進任何 log;前端讀 fragment 存 `sessionStorage`(origin 含 port,天然隔離)並 `history.replaceState` 清掉 hash;每個 `/api/*` 帶 `X-Capy-Token`,伺服器 `crypto/subtle.ConstantTimeCompare`,不符 401;靜態 `GET /` 與檔案不需 token(殼子裡沒有祕密);**不用 cookie**。**DNS rebinding**:`r.Host` 必須逐字等於 `127.0.0.1:<port>`(不收 localhost,與印出來的 URL、CLAUDE.md 的 Spotify redirect 措辭一致),不符 `421`。**Origin / CSRF**:`Origin` 若存在必須等於 `http://127.0.0.1:<port>` 否則 403;`Sec-Fetch-Site` 若存在且不是 `same-origin` / `none` → 403(連 127.0.0.1 別的 port 的 same-site 也擋);永不回 `Access-Control-*`;自訂標頭 `X-Capy-Token` 本身就讓跨站 fetch 需要 preflight 而失敗。**回應標頭**:`Content-Security-Policy: default-src 'none'; script-src 'self'; style-src 'self'; font-src 'self'; img-src 'self' https://i.scdn.co https://*.mzstatic.com; media-src https://audio-ssl.itunes.apple.com https://*.mzstatic.com; connect-src 'self'; frame-ancestors 'none'; base-uri 'none'; form-action 'none'`(兩家 CDN host 依常見回應推定,T4 拿真回應驗證再定案,不合就放寬到 `https:`;前端不得有 inline script / style,`TestWebStaticHasCSPAndNoInline` 讀 index.html 斷言)、`X-Content-Type-Options: nosniff`、`Referrer-Policy: no-referrer`、API 一律 `Cache-Control: no-store`。**祕密不進回應 / log / URL**:整個 `debug` 群組 403;三個 secret flag 在 argv 403;`auth status` 本來就遮罩、`config list` 沒祕密、`export` 的 canonical 不含憑證;精靈輸入的 secret 只在 `POST …/answer` body 裡經 loopback 進行程,伺服器不回顯、不記錄,值只進既有 keychain 寫入路徑;伺服器不記錄任何命令 args / body / query,終端機只印啟動 URL。**請求限制**:`MaxBytesReader 1 MiB`、`ReadHeaderTimeout 10s`(不設 WriteTimeout,要串流)、Go 1.22 方法路由。**生命週期**:SIGINT / SIGTERM → 砍 job → `srv.Shutdown(5s)`;token 隨行程消失。**誠實邊界**:token 擋的是其他瀏覽器來源,不是同一台機器上同一 OS 使用者的其他行程(loopback 明文 HTTP);安全邊界 = 這個 OS 使用者,與 CLI 的 argv / 環境變數相同。CLAUDE.md 新增一條硬約束(措辭見該檔)。

**代價。** token 每次啟動都變,沒有書籤可言(用終端機印的網址;換分頁要重貼);Host 嚴格比對,透過 SSH 轉埠或打 localhost 會 421(文件寫明);CSP 禁 inline style,所有動態樣式走 class / CSS 變數;CDN host 若日後變動封面會靜默不顯示(放寬只要改一行)。

### 決策 42:ISRC 頁的資料路徑、provider 豐富欄位、播放面板

**問題。** `Track.Raw` 從未被填,兩家 `do()` 直接 Decode 沒 body 副本,`store.go:3` 明寫不存原始 JSON;封面 / URL / 發行日 / popularity / preview 目前解不到;ISRC → cid 只能經 `Identity.Resolve`;沒有「cid → 含它的清單」查詢;`withCanonical` 會取 pull.lock、要 Google 登入、打 Drive、可能 COMMIT。`now --watch` 是 bubbletea 讀 os.Stdin;每次 `newProvider` = 2–3 次 `/usr/bin/security` exec + 一次 flock,每 2 s 重建不可行;`TokenSource` 把建構 ctx 存起來做 refresh(`tokenstore.go:170-175`)。

**定案。**

- **`GET /api/isrc/{isrc}?provider=all|spotify|apple|local`**(預設 all),在 package cli 直接呼叫,不經 cobra、不剖析 TSV、**不進 `runMu`**(不碰接縫、不呼叫 `defaultProvider()`;共享點只有 `BackoffStderr`(已序列化)與 SQLite,`TestWebISRCNotBlockedByRunningJob` 釘住)。流程:(1) `provider.NormalizeISRC`,空 → 400 帶 `ErrBadISRC` 訊息,不打 API;(2) 離線 `provider.ParseISRC(s) (ISRCParts, bool)`(新檔 `internal/provider/isrc.go`;`Country` 2 / `Registrant` 3 / `Year` 2 / `Designation` 5;`YearFull`:兩碼 ≤ 今年後兩碼 → 20xx 否則 19xx,ISRC 手冊 rollover 啟發式;不內建國碼 / 登記者對照表,國名由前端 `Intl.DisplayNames`);(3) 每個要求的 provider 各自 `context.WithTimeout(r.Context(), 30s)` 並行 goroutine:`newProvider` → `asISRCLookup` → `LookupISRC`;任一 provider 失敗**不讓整個回應失敗**,寫進 `providers[id].error = friendlyErr(...)`(Apple token 失效 → 指向 `capy auth login apple`,不當成查無此曲);原樣全回不消歧;(4) canonical 零副作用:`store.OpenReadOnly(200ms)` → `Dump()` → `ErrNoDB` / `ErrSchemaMismatch` / busy → `canonical: null` 帶 `canonical_error`;否則 `id := canon.NewIdentity(...)`、`cid := id.Resolve("", "", n)`(**呼叫點加註解:prov / providerID 刻意傳空,只走 byISRC;miss 會落 `i:<ISRC>` 公式,所以必須再查 `Tracks[cid]` 存在才算有**,`TestWebISRCResolveWithEmptyProviderHitsAliasSet` 釘住),回 cid、Title / Artists / Album / DurationMS、ISRC alias set、`mappings`(provider → {id, confidence, source, pinned})、`conflicts`、**含它的清單**(走訪 `Playlists[].Items`,item cid 先 `Redirect` 再比對,回 `[{pid, name, pos, links}]`,十行放 handler);回應帶 `"canonical_source":"local-cache"`,頁面標「本機鏡像,以最近一次 pull 為準」。Apple 反查回 catalog id 而 mapping 可能是 library id `i.xxx`(P4 計畫 :173):頁面用 alias set 對回同 cid 視為同一首。手動驗收案例沿用 P4:`TWK231680790` → Spotify `4P8cRZZ5Xk1wfsbULoL1Qf` / Apple `1158763998`。
- **provider 豐富欄位(用型別欄位,不用 Raw)**:`provider.Track` 加 `URL, ArtworkURL, PreviewURL, ReleaseDate string; Popularity int; Genres []string`(選填、零值 = 該平台沒給;`Raw` 不動);Spotify `trackJSON`(`spotify/client.go:120-155`)加 `popularity`、`preview_url`、`external_urls.spotify`、`album.images[]`、`album.release_date`,`toTrack` 取 `Images[0]`(Spotify 依大到小排);Apple `songJSON`(`apple/client.go:135-158`)加 `attributes.artwork{url,width,height}`、`previews[].url`、`releaseDate`、`genreNames`,`toTrack` 填 `URL = attributes.url`(現在被丟掉)、`ArtworkURL` 把 `{w}x{h}` 換成 600、`PreviewURL = Previews[0]`;`Client.Song` 第二個回傳值保留。這些欄位 `/search`、`/tracks/{id}`、`/catalog/{sf}/songs` 回應本來就有,**零額外 API 呼叫**;local 不填。註記 Spotify 2024-11 起新 app 的 `preview_url` 為 null(附錄 B 加一列)。**外部資料源不接**(MusicBrainz / ISRC registry):§8 承諾不依賴第三方服務、有 rate limit 與 UA 規範,使用者自己的兩個平台已夠豐富;封面 / 試聽由瀏覽器直接向平台 CDN 載入,capy 行程不抓圖、不快取圖。**封面的使用脈絡**:任一平台的封面只在兩種脈絡出現——播放面板(播放脈絡)與 ISRC 頁該平台的卡片,且後者永遠與該平台的外連(「在 Apple Music 開啟」/「在 Spotify 開啟」)並列,這是兩家指南允許的用法;ARCHITECTURE §8 的 Apple cover art 一列同步改成「播放脈絡或連回 Apple Music 的脈絡」。`debug lookup-isrc` 維持 Hidden、不升格(Q32)。
- **播放面板 `GET /api/now?provider=<id>`**:輪詢不串流;回 `{"provider","playing","track":{…,"artwork_url"}|null,"position_ms","device":{"name","type","volume_pct"},"error":null}`;`ErrPlayerNotRunning` / 無播放 / 未登入 / 不支援都是 200 帶 `error` 字串。預設 provider:`capy --web --provider X` 有明指(`cmd.Flags().Changed(flagProvider)`,同 `runTUI`)就用它,否則每次 `config.Load()` 的 default_provider(**不呼叫 `defaultProvider()`**);`--provider` 不自動附加到瀏覽器送的命令,前端用 `/api/commands` 的 flags 判斷目標命令吃不吃 `--provider` 再附加。前端每 2 s 一次(= `watchPollSpotify` / `watchPollApple`),`document.hidden` 時停。**不進 `runMu`**。provider 實例照 TUI 先例(`tui.go:757-783`)以**伺服器 ctx** 建一次、快取在 `s.now map[string]provider.PlaybackController`(`nowMu` 守);每次 `State` 用 `context.WithTimeout(r.Context(), pollTimeout(2s))`。作廢時機:路徑以 `capy auth` 開頭或等於 `capy config set` 的 job 結束後 `s.dropNow()`(不是每個 run 後都作廢);`State` 回錯就丟掉那個 entry;伺服器結束。播放控制鈕(play / pause / next / prev / seek / vol)不另做端點,直接 `POST /api/run` 跑既有命令,面板在 exit 後立刻多輪詢一次。

**代價。** 讀到的是本機鏡像不是 Drive 現況;每個 `Track` 多六個欄位(跟著 `[]provider.Track` 走遍 pull / push / sync 記憶體,2500 首也只是幾百 KB;進 `canon.NewTrack` 就被丟掉,不落 Drive / SQLite);試聽可能永遠只有 Apple 有;年份世紀是啟發式;ISRC 頁與進行中 job 同時打同一平台會各自吃 429 退避;面板每 2 s 一次 API;終端機另開 capy 登出時 web 的快取仍握舊 token,下一次 State 401 → 丟掉 entry;控制鈕在長 sync 期間 409。

### 決策 43:前端交付與視覺識別(摘要;完整規格在 2026-09-17-web-mode-design.md)

**問題。** 使用者要 geek 綠、冷冽霓虹、cyberpunk,並指名用 design-taste-frontend 的規則;那份 skill 自己宣告 landing page 以外(dashboard、資料表、多步驟 product UI)不在範圍,所以只套用適用的部分(主色鎖、圓角鎖、狀態完整、動效有理由、reduced-motion、無 AI 痕跡、無 em-dash 於 UI 文案),霓虹是使用者明說的 override,要「有意圖」。三份提案(相位差主控台 / HUD / 克制)+ 三位評審(規則稽核 / 產品可用性 / 品牌與工程可行性),相位差主控台 122 分勝出,移植另兩案的最佳點子,pre-flight 逐條過。

**定案。** 靜態檔放 `internal/cli/webui/`,`//go:embed webui` 進 binary,`http.FileServerFS`;vanilla HTML / CSS custom properties / ES modules;零 Node、零 CDN、零 build step、零 inline style / script。**設計讀法**:終端機的第二個視窗——dock(正在播放列 / 命令列 / log)就是 TUI 的底部四行搬進瀏覽器,七個導覽頁(播放 / 搜尋 / 清單 / 同步 / ISRC / 帳號 / 診斷)只是把同一條 capy 命令的輸出畫得更豐富的渲染器;霓虹不是第二種顏色,是同一個 `#3FB27F` 的兩個相位:進行中、聚焦、正在播的東西發光,落定之後回到平面。dial:variance 4 / motion 2 / density 8。**色票**沿用 guide.html 的名字與值(`--ink #0D1117`、`--surface`、`--surface-2`、`--line`、`--accent #3FB27F`、`--accent-dim`、`--text #C9D1D9`、`--muted #7D8794`、`--warn #D9A441`),新增 `--line-hi #646E7B`(控制項邊界,WCAG 1.4.11 三層都過)、`--text-hi #E6EDF3`(取代 `#fff`)、`--danger #ED567A`(HuhStyles 的紅)、`--accent-rgb` / `--glow` / `--glow-text` / `--scan .03`;不加第二種綠、不用純黑純白。**霓虹預算**四處可數(`:focus-visible`、進行中的 dock 頂線與 ● 脈衝、播放中的 seek 拇指、水豚 power-on 一次),app.css 一個 `glow budget` 註解塊,第五處 = review finding;box-shadow / filter 永不進 transition。**字體**:mono 是聲音(介面骨架、表頭、badge、ID、數字、TSV、命令回聲),sans 刻意安靜(曲名、藝人、REASON、說明);內嵌一支 Iosevka Fixed Regular woff2 子集(約 35 KB,不含 U+2500 方框字元:水豚是純 ASCII)當 mono,退路是系統 mono 堆疊;sans 走 `system-ui → Segoe UI → PingFang TC → JhengHei`(zh-Hant 無法內嵌 CJK)。**版面**:`body` grid 13.5rem rail + main + 全寬 dock;全直角 `--r: 0`;表格 30px 列、13px mono、斑馬、hover 不改底色改 2px `--line-hi` 左線;原子欄(`ui.go:182` 的 atomicHeader)mono + nowrap 永不截斷、沒有 ellipsis;同步表 wrapper `overflow:auto; max-height:60vh`、thead sticky、DIR / ACTION sticky left;沒有欄位排序、沒有拖曳(決策 38)。**提示**渲染在主控台區塊內(1px accent 全框 = 需要你):confirm 兩顆按鈕(remove > 0 時「套用」改危險版)、select 為 ✓ / • 前綴的 listbox、input、form(note + 欄位、密碼欄 `type=password`、驗證錯誤在欄位下);exit badge 永遠帶數字,2 / 3 是 warn 不是紅;stderr muted + 左 gutter,「stderr 是進度不是失敗」。**簽名時刻**:主控台空白時的 ASCII 水豚 power-on(`steps(3)` 2 s + glow 400 ms 退場,每 session 一次;reduced-motion 直接最終幀)。**圖示**:Phosphor regular 子集約 24 顆做成 sprite,不手畫。**單一深色主題**是刻意選擇:theme.go 只有一套、guide.html 已鎖深色、`--accent` 在白底 2.66 不過 AA、glow 相位只在深底成立。**不做**:拖曳重排、欄位排序、截斷原子欄、解析 doctor 的 ✅ / ❌、toast、spinner、亮主題、Node。

**代價。** package cli 再多四個 Go 檔 + 靜態檔 + 測試檔;沒有 build step 就沒有 minify(檔案小,不需要);字型子集要一次性離線產生(本機沒有 fonttools,Q37);前端 JS 邏輯沒有自動化測試,靠 §2 的 R-n;CSP 禁 inline 讓所有動態樣式走 class / CSS 變數。
